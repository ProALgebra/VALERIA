# Локальные MCP-серверы

В образ включаются два MCP-сервера, которые использует текущая конфигурация OpenCode:

- `mcp-memory-server` — локальная память;
- `mcp-gitlab-readonly` — GitLab API и Git-операции.

Виртуальные окружения создаются в Docker-образе. База Memory MCP хранится в едином каталоге данных проекта `data/mcp/memory` и не попадает в Git или образ. `config.env` и другие локальные секреты также игнорируются.

Файл `promt` скопирован вместе с MCP, так как OpenCode загружает его по абсолютному пути `/home/appuser/mcp/promt`.

Для подключения внешних MCP-клиентов к таскам Valeria доступен отдельный
[Valeria Tasks MCP](mcp-valeria-tasks/README.md). Адрес сервера и пользователь
задаются в его конфигурации; инструменты запускают доступные этому пользователю
таски через HTTP API, показывают статусы и итоговые ответы. Установка и примеры
конфигурации клиентов описаны в README сервера.

[Valeria Administrator MCP](mcp-valeria-administrator/README.md) предоставляет
административный API: управление пользователями, тасками и доступом, очередями,
лимитами, шаблонами и консультациями, просмотр запусков, статистики и аудита.
Учётная запись с ролью `admin` задаётся в отдельной конфигурации `VALERIA_ADMIN_*`.
